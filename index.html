Virtual Camera

Turn this phone into a live camera for Blender.

Blender addon

Install this on the computer running Blender first.

Download
  1. Unzip if your browser didn't already, or leave it zipped — either works.
  2. In Blender: Edit → Preferences → Add-ons → Install…, select virtual_cam_controller.zip.
  3. Enable Virtual Camera Controller in the add-ons list. The server starts automatically.
  4. In the 3D Viewport, open the N-sidebar → Virtual Camera panel.
  5. Read the pairing code shown there and enter it below.

Find this in Blender's Virtual Camera sidebar panel.

Your phone needs to trust Blender's connection once. Tap here, accept the security warning, then come back and press Connect again.
